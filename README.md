# Photo3D Engine

Modular, local-first experiments in portrait analysis, 2.5D rendering, and facial animation.

**Status:** early development. The public repository is initialized; no live application, production model, or published NPM package is available yet.

## Development governance

New features land through feature branches and reviewable pull requests. Do not confuse experimental landmark projections with a reconstructed 3D head. Browser AI processing is opt-in, with provenance and explicit errors.

Project context is curated in the private `DorManDel/ProjectContextManager` repository. MobiLab may link here while the lab is not deployed.

Current downloadable v0.2 TypeScript foundation exists as a separate conversation artifact and has **not** been imported into this repository.
