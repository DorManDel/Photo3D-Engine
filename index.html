DEVELOPER GUIDE / LEARN AS WE BUILD

How Photo3D actually works

A programmer-friendly explanation of the pipeline, the libraries and the limits. All code and API names stay in English.

01 · Image → landmark measurements

MediaPipe Face Landmarker detects image-relative X/Y and relative Z for facial points. These are estimates, not measured head depth. Our current model runs on the device when you explicitly press Analyze.

02 · Points → triangle surface

We use official MediaPipe connection groups to build indexed triangles. A triangle references three known vertices. We never connect random points just to create a face.

03 · Photograph → UV texture

Each vertex remembers where it came from in the source photograph using u, v. Three.js draws image pixels on the triangle surface. Eyes and hidden surfaces remain incomplete.

04 · Geometry → real reconstruction

MICA researches identity-focused face shape; DECA expression-aware geometry. They require separate Python/GPU dependencies and research license reviews. These models are not running here yet.

05 · Motion is not reconstruction

Webcam tracking estimates pose and expressions. A rig is a set of joints/controls in the avatar. Retargeting translates tracking values into that rig's naming and coordinate system.

06 · Export is a compatibility contract

GLB is a useful first portable mesh target. VRM adds a humanoid/expression convention; FBX can follow through Blender. None of these formats automatically invent valid skin weights or a working skeleton.

What each building block owns

Input Photos → Model Adapter → Geometry Contract → Renderer
↘ Metadata & Confidence → Export Adapter → Game Engine
Webcam → Motion Adapter → Retargeter → Avatar Rig

Keeping these modules separate means we can test MICA without rewriting Three.js, or use a new renderer without changing the original image analysis.

What is an adapter?

A small wrapper that translates one provider's inputs and outputs into our shared, versioned contract. It reports its model/version/license, never silently swaps in fabricated geometry and can be removed without rewriting the interface.

What is a skeleton / armature?

A hierarchy of bones with transformations. Mesh vertices have skin weights that decide how much each bone moves them. Facial expressions can additionally use morph targets (shape keys).

Why one photo cannot guarantee the back of the head

The camera only records visible pixels. A model may infer plausible hidden geometry using learned human-shape priors, but those parts are hypotheses rather than verified measurements.
